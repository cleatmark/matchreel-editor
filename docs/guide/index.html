XbotGo Review & Zoom Editor Guide

Welcome! This guide is written for anyone using the XbotGo Review Editor and Zoom Replay Editor for the first time. Learn how to navigate your match footage, refine clip timings, tag players, and craft 720p zoom replays with smooth pan tracking.

🚀 60-Second Quick Start

If you're in a hurry to review a soccer match, here is the entire workflow in 3 steps:

1
Launch & Select Game
Double-click review_editor.bat. Pick your game date from the top-left dropdown or click 📅.
2
Watch & Refine Timings
Click any row in the table. Drag the Start (green), Event (amber), or End (red) handles on the timeline.
3
Save & Push to Sheet
Press Ctrl + S anytime. Changes save atomically to disk and auto-push to Google Sheets!
💡
The Review Editor rule: It edits timings and review flags only. Video cutting, highlight reels, and final zoom mp4 encoding stay with the downstream pipeline scripts (sync_game.py and make_run_all.py).

🧰 One-Time Setup (new PC or new user)

Do this once. The project lives in XbotGo project folder (any location works; keep the folder layout inside it).

WhatHow
1. Python 3.10+Install from python.org or the Microsoft Store, then check: python --version
2. Python packagesIn the project folder: pip install -r requirements.txt (flask, gspread, numpy, opencv-python, Pillow)
3. Helper programsffmpeg, ffprobe and tesseract are already in utils\; nothing needs the Windows PATH. Check: utils\ffmpeg\bin\ffmpeg -version
4. Google Sheet access (optional)Put the service-account key (.json) in shared\secrets\ and share the workbook with that account's e-mail as Editor. Test: python tools\pipeline\sheet_sync.py tabs lists the tabs. Without it the editor still works; only Push to Sheet and Roster pull fail.
5. Logos and musicCrests and league logos go in shared\team_logos\, music beds in shared\Music\. A new opponent crest can also be added with Upload in Game Setup.
6. Start the editorDouble-click review_editor.bat (opens http://127.0.0.1:5000). If it says another copy is running, close that window first.

✅ Complete First-Game Checklist (Step-by-Step)

Follow this 10-step sequence to process any brand-new match from raw dump to final 4K video:

Step 0: Copy Smartphone Match Footage & App Dump
Connect smartphone via USB (File Transfer mode). Connect the phone by USB (File Transfer mode). Make a PC folder named MM-DD-YY (e.g. 04-01-26) and copy into it: the match videos (phone DCIM/XbotGo) as 04-01-26/Videos/*.mp4, and the whole Android/data/com.blink.blinkfocos folder as 04-01-26/com.blink.blinkfocos/. (The older DCIM/XbotGo + Android/data/... layout is still understood.) The editor lists the new date in yellow as a Dump.
Step 1: Scaffolding / Discovery
Open editor, click 📅 or pick date. If first time loading, the editor discovers the dump folder, extracts timeline, and generates initial review CSV.
Step 2: Game Setup Wizard (☰ Menu ▾ → Game Setup)
Set Home Team (pre-filled from Defaults) & Crest, Opponent Team & Crest, League (from your configured leagues), Final & Halftime scores, and Match Name.
Step 3: Generate Title Cards (🎦 Generate Cards in Wizard)
Renders Intro, Half-time, and Outro title cards (000_intro_fullgame.mp4, etc.) using chosen crests and team names.
Step 4: Refine Clip Timings in Times Table
Navigate clips. Drag Start/Event/End handles on the timeline. Ensure Start ≤ Event ≤ End (the editor warns and blocks saving if invalid).
Step 5: Atomic Save & Push to Google Sheet
Press Ctrl + S or click 💾 Save. Writes reviewed CSV with timestamped .bak sibling and synchronizes with your Google Sheet tab.
Step 6: Fast Re-cut Changed Clips (🔄 Re-cut)
Cuts edited clips locally and re-assembles the local preview reel. Logs persist server-side in tmp/task_logs/. The log window closes by itself when the run succeeds (untick auto-close to keep it open, even mid-run); the 📋 Log button reopens the last log. The same applies to Generate review. Honest status: if any clip fails to cut or the preview reel check fails, the log ends with ERROR: Re-cut finished with errors listing the clips, the dialog shows a failure instead of "Completed successfully", and nothing is reported as done.
Step 7: Craft Zoom Replays (🔍 Edit zoom)
Review framing for each zoom replay. Adjust crop box, drop pan keyframe (K) if play moves across frame, test preview (R), and press Ctrl + S to save plan. Unreviewed silent center crops are strictly blocked from rendering!
Step 8: Render & Verify Zoom Replays (▶ Render exact / All)
Renders 720p previews with verify_zoom.py edge/length verification. If any clip is missing or flagged, the drawer ends RED with a clear failure alert.
Step 9: Featured Player Spotlight Reels (☰ Menu ▾ → Featured Player)
Select featured roster player(s) (e.g. #7 Chloe Bennett or #10 Ava Patterson). Generates team highlight reel plus individual player spotlight reel(s). The reel pipeline shows a progress line per stage in the log window ([clips], [replays], [reels], team highlights done); it can take 30-50 minutes for a full game, and you can close the window and reopen it from the menu.
Step 10: Final 4K Production (☰ Menu ▾ → Final 4K Production)
Runs 6 pre-flight checks, generates serial batch script (run_everything_<date>.bat), shows the exact command, and launches after explicit confirmation. Safe to pause and resume!

⚡ How to Launch the App

Everything runs 100% locally on your computer with zero external server dependencies:

  • Method 1 (Recommended): Double-click review_editor.bat in the project root folder (review_editor.bat). It automatically checks the port, launches the local server, and opens your default browser at http://127.0.0.1:5000.
  • Method 2 (Command Line): Open PowerShell, navigate to the folder, and run: 
    python tools\editor\server.py
🛡️
Duplicate Launch Protection: If the editor is already running, starting a second copy will print: Editor is already running on port 5000 (started HH:MM:SS). Close that window first. This protects your CSV files and prevents background conflicts.

The table displays all detected game marks, goal attempts, fouls, and manual bookmarks in chronological order:

Times Table Close-up
Figure 2: Table showing clip numbering, combined Type & Mark time pill (M (2:43), G (8:48)), clickable 3-cell timing buttons (Start, Event, End), player number, instruction chips (ZOOM 🔍, SKIP), and notes.

Key Table Features:

  • Click Row to Jump (Seek to Start): Clicking anywhere on a table row (or navigating with ArrowUp / ArrowDown) immediately seeks the video to that row's action_start timestamp (falling back to mark if start is unconfigured) and centers the 30-second timeline slider, so review and tuning playback begins right before the play unfolds. Clicking the Type (Mark) pill specifically seeks the video to the mark.
  • Ground-Truth Mark Immutability: Match marks (video_time) are recorded directly from the gimbal and smartphone during the match and serve as immutable ground truth. Marks cannot be edited, typed over, or dragged on the slider. If a mark was placed poorly or isn't needed, flag the clip with X (SKIP); if a key play was missed during recording, press Insert to add a net-new row at the current playhead.
  • Click Time Cells to Jump: Clicking any time cell (Type (Mark), Start, Event, or End) seeks the video immediately to that exact second and highlights the corresponding timing line with a blue glow.
  • Typing a time: double-click (or click the pencil on) a Start, Event or End time, type mm:ss, then press Enter to commit or Esc to cancel. Tab commits and moves straight to the next time of the same row (Shift+Tab goes back), so you can type Start, Tab, Event, Tab, End without touching the mouse. Typed digits never trigger the 1/2/3, Z or X hotkeys while a time field is open.
  • Double-Click to Edit: Double-click Start, Event, or End to type a replacement timestamp (e.g. 12:45). Press Enter to commit.
  • Unreviewed Replay Badges (UNREVIEWED): Clips marked for zoom that have not yet had their replay crop visually confirmed display an amber badge directly adjacent to ZOOM 🔍, making it effortless to scan down the table and find replays needing review.
  • Dirty Tracking (*): Any row with unsaved changes immediately displays an asterisk next to its clip number (e.g. 5*). Saving with Ctrl + S clears the asterisks.
  • Manual Rows (➕ Add row): Press Insert to insert a new row right at the current video playhead. It pre-fills notes: manual, calculates the 24-hour clock and game clock, and renumbers clips dynamically.
  • Column & Video Splitters: Drag the vertical divider between the table and video to rebalance pane widths, or drag the horizontal splitter under the video player to adjust video height!

📐 Unplaced Replay Stage & Auto-Frame

Brand-new zoom replays start in an Unplaced state to prevent silent off-target center renders:

  • Stage Click-to-Frame: Simply click on the video stage where the action is taking place; the 16:9 crop box immediately drops centered on your click coordinate.
  • 📐 Auto-frame Button: Centers the box at [1152, 450] (2.5x zoom) (safe upper midfield) and flags it as auto-placed awaiting your review.
  • Auto-frame All Unplaced: One-click convenience to apply upper-midfield framing to every unplaced replay across the entire game at once.
  • 👍 Looks Good Approval: Auto-framed clips remain marked UNREVIEWED until either nudged/adjusted or explicitly approved by clicking 👍 Looks Good next to Save Plan. Visiting an auto-placed clip and pressing Save without reviewing it will not silently approve it.

🔢 Precision Typed Inputs: Replay Window, Trims & Freeze Hold

The Replay Window offsets (Window Start, Window End), Cut Trims, and Freeze Hold are precision typed numeric fields. Dragging handles on the scrubber controls video scrubbing and keyframe placement; adjusting replay window boundaries is done by typing exact float values into these inputs (e.g. type -5.5 or +2.5, then press Tab or Enter).

  • Window Start Offset: Sets how many seconds before the event the slow-motion replay begins (default: -2.5s). When you adjust the Start Offset, the START anchor moment shifts in source time. The editor immediately warns you with a toast notification to verify framing and automatically seeks the video playhead to the new start moment so you can confirm or reposition the amber crop box.
  • Window End Offset: Sets how many seconds after the event the replay ends (default: +2.0s). Increase this (e.g. to +3.0s) to capture lingering post-goal celebrations.
  • Live Duration Readout: The sidebar displays a live duration readout (e.g. 8.0s source = 16.0s replay) so you immediately see the impact at 0.5x slow-motion.
  • Status Badge Tracking & Stale Detection: If a replay was previously rendered and you subsequently modify its window offsets, trims, or crop box, the editor immediately marks its status badge as RENDERED (stale) in amber. This alerts you that the rendered review file and downstream 4K master are out of date until re-rendered.

▶️ Instant Replay Preview (R)

Press R or click ▶ Preview Replay (R). The video plays at 0.5x slow-motion while the on-screen crop box animates smoothly along your exact smoothstep glide path. This lets you verify the framing in real time without rendering a single frame!

⚠️ Quality Framing Guarantee: Unreviewed Crop Blocking

The Chameleon gimbal tracking operates in sensor space and has mechanical pan lag. Silent center crops ([1152, 648]) often result in empty grass or missed shots. To prevent unwatchable footage:

  • Silent Center Crops Never Render: An unreviewed or auto-placed zoom clip strictly blocks both single-clip and batch rendering until you frame the box and save the plan (Ctrl + S).
  • Unreviewed Clips Block List: Clicking "Render all zoom clips" when unreviewed clips exist opens a modal listing every unreviewed clip with direct clickable links so you can jump straight to them.
  • Render Reviewed Only: Need a fast preview of already-framed clips? The modal offers a "Render Reviewed Only (X clips)" button to render only what you have approved.
  • Honest Final Status: If verify_zoom.py reports any clips as MISSING or FLAGGED, the log drawer turns RED and reports a failed status. It will never falsely claim success when clips are missing.
  • Server-Side Log Persistence: Task logs are saved to tmp/task_logs/ on disk. Closing the browser tab or restarting the server will never wipe out your render history.

↩️ Remove & Restore Zoom (Undo Safety)

Decided this clip doesn't need a zoom replay?

  • Remove zoom: Click Remove zoom. An in-page confirmation modal asks you to confirm. It removes the zoom flag from the CSV and moves the replay to removed in zoom_state.json.
  • Restore zoom: Changed your mind? A Restore zoom button immediately appears! Clicking it restores the CSV flag and moves the saved replay back from removed with byte-identical safety.

🛡️ Unsaved Changes Guard (Keep Editing / Discard / Save)

Accidental navigation or closure never loses your zoom work. If any edits were made to the crop box, zoom ratio, keyframes, replay window, or trims, attempting to return to the Review Editor (via Escape, clicking the ← Return to Review button, or closing the tab) immediately opens the Unsaved Zoom Changes guard modal:

  • Keep Editing: Closes the dialog and stays in the Zoom Editor right where you were.
  • Discard Changes: Reverts all unsaved changes and returns directly to the Review Editor.
  • Save & Return: Saves your zoom plan to zoom_state.json and returns to the Review Editor in a single click.

🚀 Final 4K Production

When all clip timings and zoom replays are verified, click ☰ Menu ▾ → Final 4K Production...:

1
Automated Pre-Flight & Duration Estimate
Validates game setup, roster presence, title cards, 0 unreviewed zoom clips, valid timing order, and 20+ GB disk space. Displays estimated total render time (e.g. ~1.8 hours (107 min)).
2
🔍 Dry Run Verification
Click 🔍 Dry Run to simulate batch generation and verify every command line without invoking ffmpeg.
What the run file is: run_everything_<date>.bat is only a one-line launcher for tools\pipeline\run_everything.py (title cards → full game → 4K clips/replays/reels → output check). The Python runner does the work, skips finished pieces, and writes run_everything_<date>.log, which ends with ALL OK when every check passes. Press Start again after a Cancel or restart and it resumes where it stopped.
3
Typed "START" Confirmation
Type START to unlock the launch button, guaranteeing no accidental multi-hour encoding runs.
4
Detached Visible Console Runner
Runs in an independent console window that survives browser closing. Writes to run_everything_<date>.log and saves PID.

Production Protection & Controls:

  • Modifying Action Locks: While production is running, actions that could alter output files (Re-cut, Render Zoom, Generate Cards, Generate Reels) are locked and return 409 Conflict. A prominent banner displays: "Production is currently running. Editing actions are locked."
  • ⏹ Cancel Run: Need to stop encoding? Click ⏹ Cancel Run in the production dialog. It terminates the entire process tree cleanly via taskkill /F /T, appends [CANCELLED BY USER] to the log, and unlocks the workspace.
  • Strict Batch Execution Order: make_run_all.py enforces strict stage dependencies:
    1. Title cards: make_reels.py --stage cards
    2. Full game video: concatenated multi-batch footage
    3. 4K clips, replays & highlight reels: make_reels.py --stage all
    4. Checks: automated length and file integrity verification

💡 Common Editing Recipes

Recipe A: "The shot was cut off before entering the goal"

  1. Select the goal row in the table. The timeline focuses on the 30s zoom window.
  2. Drag the red End handle to the right until the ball clearly ripples the net.
  3. Press Ctrl + S. Done!

Recipe B: "Adding a great build-up pass the AI missed"

  1. Scrub the video to the pass moment.
  2. Press Insert (or click ➕ Add row).
  3. A new row appears with notes: manual. Drag the green Start and red End handles to bracket the pass.
  4. Press Z if you want a zoom replay for it!

Recipe C: "Tracking a striker sprinting across the penalty box"

  1. Click ZOOM 🔍 on the goal row to open the Zoom Editor.
  2. Frame the striker at the start with the amber box (select 3.0x zoom).
  3. Press Space until the striker reaches the far post, then pause.
  4. Press K, then drag the blue box onto the striker.
  5. Press R to watch the camera glide smoothly across with the run.
  6. Click ⚡ Render exact. Verify the green PASS badge. You're done!

Recipe D: "Make a replay longer or shorter & rebuild 4K masters"

  1. Open the replay in the Zoom Replay Editor by clicking ZOOM 🔍 on its table row.
  2. In the right Inspector panel under Replay Window, type new values into Start Offset (e.g. type -5.5 to start 5.5s before the shot) or End Offset (e.g. type +2.5 to capture celebrations).
  3. Notice that changing Start Offset automatically moves the playhead to the new start moment with an on-screen prompt: verify that the amber crop box accurately frames the action at this earlier start moment.
  4. Press Ctrl + S to save the plan. Notice the status badge reflects RENDERED (stale). Click ⚡ Render exact to re-render the 720p review preview.
  5. To update your full-quality 4K deliverables, return to the Review Editor and open ☰ Menu ▾ → 🚀 Final 4K Production.... The dialog will display a prominent ⚠️ 4K Outputs Out of Date indicator listing your modified clips.
  6. Click ⚡ Rebuild Changed 4K Replays & Reels. In just ~5 to 8 minutes (~1m per modified 4K replay + ~3.5m highlight reels), the pipeline re-renders only the modified 4K replays and re-assembles the highlight reels (skipping all untouched clips!).

❓ Troubleshooting & FAQ

⚠️
"Editor is already running on port 5000": You already have a server window open. Check your Windows taskbar for the running terminal, or close it before launching again.
🔴
Red "Server process is stale" top banner: Python or HTML files were updated while the server was running. Simply close the server terminal and double-click review_editor.bat to restart fresh.
🧹
Final 4K on a game you already tidied: After Tidy Output Folder the timeline lives in work\ and the finished videos in final\. The Final 4K dialog then shows only a short note with an ↩ Untidy this game... button, because there is nothing left to produce (the checks, batch script and Start are hidden). To re-render a tidied game from scratch, open Tidy Output Folder and click ↩ Untidy...: it previews, then moves work\ and final\ back into the game folder (nothing is overwritten); Tidy again when you are done.
📑
"File Changed Elsewhere" when saving: The reviewed file on disk changed after this page loaded it (a second browser tab, or a manual edit). Choose Cancel, reload the page to see the newer version, and redo your last edits; choose Overwrite only if the table on this page is the one you want. Closing or reloading the tab with unsaved edits also asks first.
⏱️
Re-cut takes several minutes the first time: Cutting every clip of a new game takes about 5-10 minutes; the Re-cut window lists [3/25] ok ... per clip. The Final 4K cmd window also prints one line per clip, per zoom replay and per reel. You can close the window; run Re-cut again after an interruption and finished clips are kept.
🔄
Restarting the editor: Start it with review_editor.bat (or review_editor.sh). Creating an empty file tmp\restart_editor.flag then makes the editor restart itself in the same window within a few seconds (it waits while a background job is running). An editor started any other way has to be closed and started again by hand.
💾
Where are my edits saved? All changes are saved to out\reviewed\<date>_reviewed.csv using strict 15-column atomic backups. Whenever you press Ctrl + S, the editor also automatically syncs the entire table directly to your game's Google Sheet tab!
